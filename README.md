# Жребий: полноэкранные сцены

Mini App для Telegram-бота игры «Жребий». Бот открывает эти страницы на весь экран внутри Telegram.

Страница публикуется через GitHub Pages: `https://alexeyptsk.github.io/zhrebiy-game/`.

## Сцены

| Адрес | Что показывает |
| --- | --- |
| `?scene=doroga` | Дорога в театр: видео героя, который идёт к Театру Диониса |

Новая сцена: положить видео в `media/` и добавить запись в объект `SCENES` в `index.html`.

Здесь только публичные файлы сцен. Тексты, документы и код бота лежат в основном репозитории проекта.
