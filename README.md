# Жребий

Образовательная игра о Великих Дионисиях 421 г. до н. э. Игрок — афинский гражданин, которого жребий выбрал судьёй театрального состязания. Акт I.

Играть: https://alexeyptsk.github.io/zhrebiy-game/

Работает в браузере и как Telegram Mini App на весь экран.

## Как устроено

- `index.html`, `style.css`, `game.js` — игра.
- `data/act1.json` — тексты. Не правьте вручную: файл выгружается скриптом `export_web.py` из основного репозитория проекта, где тексты лежат в `Тексты игры/акт_1.yaml`.
- `media/` — кадры и видео.
- `?scene=doroga` — отдельная полноэкранная сцена «Дорога в театр» для чат-версии бота.
