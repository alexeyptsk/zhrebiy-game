# «Жребий» — веб-версия, акт I

Афины, Великие Дионисии 421 г. до н. э. Игрок — гражданин, которого жребий выбрал судьёй от его филы. Он смотрит три комедии, разбирает шутки («над чем» и «кто засмеётся»), слушает слухи, спорит с соседом и голосует. Около 15 минут.

Сделано с ИИ (Claude) 20.11.2026 по материалам команды: гугл-док с ТЗ, design.md, слои карты Афин (архив от 20.11), лист спрайтов героя, сцены театра и урны, видео «Дорога в театр». Перед сдачей команда проверяет тексты и правит.

## Как запустить у себя
Нужен любой локальный сервер (из-за модулей и JSON браузер не откроет игру двойным щелчком):

```bash
cd игра-жребий && python3 -m http.server 8765
```

Потом открыть http://localhost:8765. Сборка не нужна: Phaser 3.80.1 грузится с cdnjs, код — обычные ES-модули.

## Как заменить арт
- **Герой:** `assets/sprites/hero_sheet.webp` — сетка 4×4 (стоит: вправо, влево, к нам, от нас; ряды 2–4 — шаг вправо, к нам, от нас). Используется только для героя.
- **Мужчины:** `assets/sprites/men_sheet.webp` — 4 персонажа по ряду, в каждом ряду стойка и три жеста. Ряд 1 — архонт, 2 — сосед-гражданин, 3 — гость с Хиоса, 4 — жрец Диониса. Знаток и глашатай — те же старик и бородач со сменой цвета плаща. Зрители в театре — уменьшенные мужчины с плащами разных тонов.
- **Женщины:** `assets/sprites/women_sheet.webp` — две женщины (стоят и идут), ходят по агоре. В театр не посажены: учёные спорят, бывали ли там женщины.
- Белый фон у всех листов убирается автоматически; кадры выравниваются по ступням. Портреты в диалогах вырезаются из кадров тех же листов.
- **Звук:** положить записи в `assets/audio` и подключить в `src/audio.js`.

## Что важно знать
- Координаты точек, мест A/B/C и NPC — предложения из архива слоёв, команда их ещё не утверждала.
- Слои карты — реконструкция генератором, не пиксельно точные вырезки (см. README архива).
- Строки «Фратеров» Левкона придуманы условно: от пьесы осталось почти одно название. «Льстецы» Эвполида — пересказ фрагментов. «Мир» Аристофана — пересказ сохранившегося текста.
- Победитель в игре выбирается случайно. Настоящий итог 421 г. — в карточке разбора.
